# Course AI Test Manual

Repo lưu trữ tài liệu thực hành cho khóa học **AI Manual Test** — nơi ghi lại các tài liệu kiểm thử (SRS, test case, ...) được xây dựng với sự hỗ trợ của AI (Claude) dựa trên khảo sát thực tế các ứng dụng/website mẫu.

## Nội dung hiện có

| File | Mô tả |
|---|---|
| [SRS-Login-Module.md](SRS-Login-Module.md) | Đặc tả yêu cầu phần mềm (SRS) cho module Login, khảo sát trên hệ thống demo [Perfex CRM – Anh Tester](https://crm.anhtester.com/admin/authentication) |
| [Test-Strategy-Login-Module.md](Test-Strategy-Login-Module.md) | Test Strategy cho module Login theo chuẩn ISTQB / ISO 29119-3 |
| [Testcase/TC_Login.md](Testcase/TC_Login.md) | Bộ 37 test case cho module Login và Forgot Password (Happy path, Negative, Edge case) |

## Mục đích

- Thực hành quy trình phân tích một chức năng thực tế và biên soạn tài liệu SRS.
- Làm nguồn đầu vào để thiết kế test case, checklist kiểm thử cho các buổi học/thực hành.

## Cách sử dụng

Mỗi tài liệu `.md` trong repo tương ứng với một module/chức năng được khảo sát. Đọc trực tiếp file Markdown để xem đặc tả, danh mục thông báo lỗi, use case và test case gợi ý.
